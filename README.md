# 樂齡肩髖關節復健訓練應用

專為樂齡族群設計的肩關節和髖關節復健訓練應用程式。

## 🎯 功能特色

- 📹 YouTube 示範影片
- 📊 訓練進度追蹤
- ⏱️ 休息計時器
- 📱 手機平板適配
- ✅ 六組專業復健運動

## 🚀 立即使用

訪問：https://YOUR-USERNAME.github.io/senior-rehab-app/

## 📋 運動項目

### 肩關節復健
1. 肩關節前彎運動
2. 肩胛骨收縮運動
3. 肩關節外旋運動

### 髖關節復健
1. 髖關節屈曲運動
2. 髖關節外展運動
3. 臀橋運動

## ⚠️ 注意事項

請在開始運動前諮詢醫療專業人員。如感到疼痛或不適，請立即停止運動。
